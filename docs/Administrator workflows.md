# Administrator workflows

Review alerts and linked scan evidence. Create or open the linked incident, assign an investigator, record notes, move it through investigation and record resolution. High/Critical scans create containment incidents automatically. Reassignment is an explicit case action; there are no configurable assignment rules or scheduled escalations.

Active threat blocks take precedence over website approvals and whitelist entries. Resolve the latest linked investigation, then explicitly confirm an administrator release with a reason. Case resolution alone does not lift containment.

Administrators retain account approval, 2FA, website reviews, exceptions, privacy and retention, detection evaluations, usability records, reports and delivery, and audit review. Scores follow the current risk configuration. Policy draft/review/activation screens have been removed.
