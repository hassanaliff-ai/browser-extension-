# Publishing user documents

Keep the user's documents local. Do not upload proposals, reflections, screenshot portfolios, acceptance forms, or their image archives and indexes to GitHub. The project plan is the only user document permitted for publishing.

This restriction does not stop updates to practical extension/database source code, tests, configuration, technical setup documentation or the installable extension ZIP. Preserve local document copies when removing them from Git tracking. Do not rewrite published Git history without an explicit request.

# Save completed project work

The user requests that completed project source, tests, configuration, technical
setup notes and verified extension ZIP updates be committed and pushed to this
GitHub repository after relevant checks pass. Preserve newer upstream changes
when integrating older local work. Keep personal documents, credentials, `.env`,
account data, databases, runtime logs and local backups out of commits. Report
the saved commit and any genuine publishing blocker. A GitHub upload does not
automatically replace files in an unpacked Chrome extension on another device.
